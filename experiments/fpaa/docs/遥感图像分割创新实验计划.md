# 遥感图像分割创新实验计划

## 1. 研究主题与目标

### 1.1 主题
Foundation-Model-First Domain Generalization and Adaptation for Remote Sensing Segmentation

### 1.2 核心目标
1. 以 Transformer/SAM 基础模型为核心，构建跨域遥感分割主线方法。
2. 用高质量伪标签与提示学习替代传统重对抗 UDA 作为主要增益来源。
3. 将 UDA 从主方案降级为辅助模块或对照组，验证其真实边际贡献。
4. 在 LoveDA Rural→Urban 与 Urban→Rural 两个方向上实现稳定且可复现的提升。

### 1.3 目标指标
1. 主指标：mIoU、mF1。
2. 边界指标：Boundary F1（或 Boundary IoU）。
3. 迁移指标：跨域性能降幅 Delta（源域到目标域的性能差）。
4. 稳定性指标：不同随机种子下均值与标准差。
5. 复杂度指标：训练时长、推理速度、显存占用。

## 3. 方法设计

### 3.1 主方案（优先）
FM-First Prompt-Quality Aware Adaptation（简称 FPAA）

流程分为五步：
1. 基础模型初始化：使用 SAM/ViT 编码器或仓库现有 Transformer 主干。
2. 自适应提示生成：基于 CAM 或激活响应生成点提示与框提示。
3. 高质量伪标签构建：融合置信度、边界一致性、连通性得到质量分数。
4. 质量感知自训练：对高质量区域增强监督，对低质量区域降权或忽略。
5. 轻量域适配（可选）：仅在后期引入弱对抗或特征校正，作为增益项而非主驱动。

### 3.2 关键创新点
1. FM-First：先用基础模型能力建立强上限，再讨论是否需要域适配。
2. 提示质量感知：提示参与样本筛选与损失加权，而不是固定输入。
3. 边界一致性驱动：边界分支用于伪标签质量控制，而非仅做辅助损失。
4. 轻量适配策略：减少传统重对抗训练带来的不稳定性和高调参成本。

### 3.3 对照与扩展方案
1. 对照 A：传统 UDA（GLGAN 原始版本）。
2. 对照 B：SAM + 自训练（不做质量筛选）。
3. 扩展 A：不确定性融合推理（重叠窗口 + 高斯加权 + TTA）。
4. 扩展 B：多模态缺失鲁棒训练（RGB+DSM，随机模态失活）。
5. 扩展 C：Source-Free/Test-Time Adaptation（仅目标域在线更新）。

## 4. 实验设置

### 4.1 数据集与任务
1. 数据集清单（基于当前工作区）：
   1) LoveDA：autodl-tmp/dataset/LoveDA/Train、Val、Test（主线跨域数据）。
   2) MMHunan：autodl-tmp/dataset/Hunan_Dataset/train、val、test（多模态鲁棒扩展）。
   3) ISPRS Potsdam：autodl-tmp/dataset/Potsdam/*（跨城泛化与辅助验证）。
   4) ISPRS Vaihingen：autodl-tmp/dataset/Vaihingen/*（跨城泛化与辅助验证）。
2. 主任务优先级：
   1) T1（主任务）：LoveDA Rural→Urban 与 Urban→Rural。
   2) T2（辅助验证）：Potsdam↔Vaihingen 跨城迁移或跨域测试。
   3) T3（扩展）：MMHunan 多模态缺失鲁棒与泛化测试。
3. 统一划分与复现实验约束：
   1) 优先使用各仓库脚本默认划分（与既有论文可比）。
   2) 固定 3 个随机种子（建议 3407、3408、3409）。
   3) 所有任务统一记录 patch size、stride、batch size、epoch 与学习率。
   4) 若 LoveDA 在本地目录结构与脚本默认不一致，先建立索引文件而非改动原始数据。

### 4.2 对比方法
1. 纯分割基线：MFNet/FTransUNet 主干（不做域适配）。
2. FM 基线：SAM_RS 或 MFNet（SAM 编码器）直接微调。
3. FM + 自训练：伪标签训练，无质量筛选。
4. FM + 质量感知自训练（V1）：仅置信度筛选。
5. FM + 质量感知自训练（V2）：置信度 + 边界一致性。
6. FM + 质量感知自训练（V3）：置信度 + 边界一致性 + 连通性（完整版 FPAA）。
7. 传统 UDA 基线：GLGAN_LoveDA_R2U / GLGAN_LoveDA_U2R。
8. FM + 轻量 UDA：在 FPAA-V3 基础上加弱对抗或特征对齐。

### 4.3 消融实验
1. 提示类型：点、框、点框融合。
2. 质量评分组件：仅置信度、置信度+边界、置信度+边界+连通性。
3. 训练策略：固定阈值筛选、动态阈值筛选、课程式阈值。
4. 适配策略：无适配、轻量适配、传统对抗适配。
5. 损失构成：仅分割损失、分割+边界损失、分割+边界+适配损失。
6. 数据集泛化消融：
   1) 仅 LoveDA。
   2) LoveDA + ISPRS 预训练初始化。
   3) LoveDA + MMHunan 辅助多模态鲁棒训练。

### 4.4 评估与统计
1. 每组实验至少跑 3 个随机种子。
2. 报告均值与标准差。
3. 输出典型可视化：成功案例、失败案例、边界对比图。
4. 统计显著性：关键主表建议补充 t 检验或非参数检验。
5. 额外报告项：
   1) LoveDA 两方向平均提升（R→U 与 U→R 的宏平均）。
   2) 训练成本（每 epoch 时间、总显存峰值、总训练时长）。
   3) 推理策略差异（单尺度、滑窗、TTA）对指标增益。

### 4.5 数据到实验的落地流程（细化）
1. Step A：数据核验
   1) 检查四个数据集目录完整性（图像、标签、DSM/辅助模态）。
   2) 统计每个子集样本数并写入 docs/tables/dataset_stats.md。
2. Step B：统一索引
   1) 为 LoveDA 生成 train/val/test 索引（可附带 Rural/Urban 域标记）。
   2) 为 Potsdam/Vaihingen 生成 tile 列表与训练/测试切分文件。
3. Step C：预处理与缓存
   1) 大图切 patch（保持与原脚本一致的窗口设置）。
   2) SAM 离线伪标签导出到固定缓存目录，避免重复推理。
4. Step D：基线训练
   1) 先跑 FM 基线（无筛选），固定随机种子和记录模板。
   2) 输出第一版主表（仅 LoveDA R→U）。
5. Step E：质量感知训练
   1) 依次启用 3 种筛选：无筛选、仅置信度、置信度+边界（再到完整版）。
   2) 每次只改一个变量，其余参数固定。
6. Step F：对照与扩展
   1) 跑 GLGAN 双方向对照。
   2) 跑 FPAA + 轻量 UDA（后期接入）验证边际收益。
7. Step G：复现与统计
   1) 完成 3 seeds 重复。
   2) 计算均值、标准差、显著性并生成最终表格。

## 6. 风险与应对

1. 风险：伪标签噪声过高导致训练不稳定。
   应对：动态阈值 + 冷启动阶段仅用高置信样本 + 边界一致性过滤。
2. 风险：SAM 推理耗时高。
   应对：离线生成伪标签并缓存；分批处理与并行。
3. 风险：FM 提升明显但跨域仍掉点。
   应对：引入轻量适配层、类别重加权和目标域高置信重采样。
4. 风险：结果波动大。
   应对：固定随机种子、统一评估脚本、增加重复次数。
5. 风险：传统 UDA 对照结果异常好。
   应对：核对预处理与训练轮数一致性，补充公平对照设置说明。
