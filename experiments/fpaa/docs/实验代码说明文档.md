# 实验代码说明文档

## 1. 目的

本说明文档用于解释 experiments/fpaa 目录下各脚本与配置文件的职责，帮助你快速复现实验主线：

1. LoveDA 的 FM 基线训练。
2. LoveDA 的 GLGAN 对照训练。
3. 小规模消融矩阵批跑。

## 2. 文件与用途

### 2.1 scripts/00_check_data.sh

作用：检查数据集目录是否存在，并统计图像文件数量。

输入参数：

- 第一个位置参数: 数据集根目录。
- 若不传参，默认读取 DATASET_ROOT 环境变量。

输出：

- 各子目录是否存在。
- 各子目录图像数量统计。

适用场景：

- 初次迁移到新机器后核验数据。
- 每轮大规模训练前做快速健康检查。

### 2.2 scripts/10_run_fm_baseline.sh

作用：运行 FM 基线（MFNet 或 SAM_RS）。

输入参数：

- 第1个参数 Backbone: MFNet 或 SAM_RS。
- 第2个参数 Direction: R2U 或 U2R。
- 第3个参数 Seed: 随机种子。
- 第4个参数 PythonExe: Python 可执行程序。

行为说明：

1. 生成 run id 与日志文件。
2. 注入环境变量 EXP_DIRECTION、EXP_SEED。
3. 调用对应训练入口：
   - MFNet/train.py
   - SAM_RS/train.py

注意：

- 由于原仓库训练入口大多在脚本内部固定数据配置，你需要先确认对应模块里的 DATASET 与路径设置。

### 2.3 scripts/20_run_glgan_baseline.sh

作用：运行 LoveDA 的传统 UDA 对照。

输入参数：

- 第1个参数 Direction: R2U 或 U2R。
- 第2个参数 Seed: 随机种子。
- 第3个参数 PythonExe: Python 可执行程序。

行为说明：

1. Direction=R2U 时调用 GLGAN/GLGAN_LoveDA_R2U.py。
2. Direction=U2R 时调用 GLGAN/GLGAN_LoveDA_U2R.py。
3. 自动输出日志到 experiments/fpaa/logs。

注意：

- 运行前需确认 GLGAN 脚本中的数据目录与预训练权重路径。

### 2.4 scripts/30_run_ablation_matrix.sh

作用：按 CSV 实验矩阵批量启动实验。

输入参数：

- 第1个参数 MatrixCsv: 消融矩阵文件路径。
- 第2个参数 PythonExe: Python 可执行程序。

行为说明：

1. 读取每一行实验配置。
2. 写入环境变量 FPAA_QUALITY_MODE 与 FPAA_USE_LITE_DA。
3. 根据 backbone 自动调用 FM 或 GLGAN 启动脚本。

注意：

- 若当前训练脚本尚未读取 FPAA_QUALITY_MODE 等环境变量，你需要在训练代码中补充读取逻辑。

## 3. 配置文件

### 3.1 configs/experiment.env.example

作用：保存环境变量模板，统一跨机器配置。

关键变量：

- PYTHON_EXE
- DATASET_ROOT
- DEFAULT_SEED
- DEFAULT_DIRECTION
- DEFAULT_BACKBONE
- EXP_ROOT

### 3.2 configs/ablation_matrix.csv

作用：定义批量消融运行计划。

当前示例包含：

1. 无筛选。
2. 仅置信度筛选。
3. 置信度+边界筛选。
4. 完整 FPAA。
5. 完整 FPAA + 轻量适配。

## 4. 推荐运行流程

1. 数据核验：执行 scripts/00_check_data.sh。
2. FM 基线：执行 scripts/10_run_fm_baseline.sh。
3. UDA 对照：执行 scripts/20_run_glgan_baseline.sh。
4. 小规模消融：执行 scripts/30_run_ablation_matrix.sh。
5. 汇总结果：将关键指标整理到 experiments/fpaa/results。

## 4.1 auto-dl Linux 示例命令

```bash
cd experiments/fpaa
chmod +x scripts/*.sh

bash scripts/00_check_data.sh /root/autodl-tmp/dataset
bash scripts/10_run_fm_baseline.sh MFNet R2U 3407 python
bash scripts/20_run_glgan_baseline.sh U2R 3407 python
bash scripts/30_run_ablation_matrix.sh configs/ablation_matrix.csv python
```

说明：

1. 这 4 条命令覆盖数据检查、FM 基线、GLGAN 对照、消融批跑。
2. 若你在 auto-dl 使用 conda 环境，建议先 conda activate 再执行。

## 4.2 Windows 兼容

如需在 Windows 本地复现，可继续使用 scripts 目录下同名 ps1 脚本。

## 5. 日志与结果管理建议

1. 每次运行使用唯一 run id。
2. 每个 run 至少记录：dataset、direction、method、seed、mIoU、mF1、BoundaryF1、训练时长、显存峰值。
3. 可视化建议按 run id 建子目录，便于论文插图溯源。

## 6. 下一步可选增强

1. 在训练代码内增加环境变量读取，避免频繁手改脚本。
2. 新增统一评估脚本，自动计算并汇总多次 seed 的均值与标准差。
3. 增加失败重试与断点续训逻辑，提升批跑稳定性。
